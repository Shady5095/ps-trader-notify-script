# 🎮 رادار دوبيزل مصر لأجهزة PlayStation 5 الذكي

اسكربت تلقائي ذكي لمراقبة موقع **دوبيزل مصر (Dubizzle Egypt)** للبحث عن أجهزة **PlayStation 5** بجميع أنواعها وموديلاتها، مع استخدام **Google Gemini AI** للتحقق الدقيق من أن الإعلان لجهاز كونسول حقيقي وليس مجرد أسطوانة ألعاب أو ذراع تحكم أو جهاز PS4، مع إرسال **إشعار فوري ومجاني 100%** على هاتفك المحمول بمجرد نزول أي جهاز جديد.

---

## 🌟 مميزات الاسكربت

1. **بحث شامل في جميع الأقسام (All Categories):** لا يقتصر على قسم ألعاب الفيديو فقط، بل يبحث في كافة أقسام دوبيزل لاصطياد الأجهزة التي قد ينشرها أصحابها في أقسام أخرى بالخطأ.
2. **قاموس كلمات دلالية ضخم (عربي وإنجليزي):** يغطي كل الصيغ والمفردات الممكنة لكتابة PS5 في مصر:
   - `ps5` / `ps 5` / `playstation 5` / `play station 5` / `playstation5`
   - `بلايستيشن 5` / `بلاي ستيشن 5` / `بلايستيشن5` / `بلاي ستيشن ٥` / `بلايستيشن ٥`
   - `ps5 slim` / `ps5 pro` / `بلايستيشن سليم` / `بلايستيشن برو`
   - `بي اس 5` / `بليستيشن 5` / `جهاز ps5`
3. **فحص ذكي بـ Google Gemini AI:** يحلل عنوان الإعلان ووصفه وسعره لفلترة الإعلانات بدقة:
   - ✅ يقبل: أجهزة PS5 الحقيقية (Fat, Slim, Pro, Disc, Digital) حتى لو معها دراعات أو ألعاب إضافية كباقة.
   - ❌ يستبعد: أسطوانات الألعاب فقط (CDs)، دراعات التحكم فقط (DualSense)، أجهزة PS4 حتى لو كُتب بالوصف "بدل بـ PS5"، خدمات الصيانة والإيجار وطلبات الشراء.
4. **تحديث تلقائي كل 5 دقائق:** يعمل في الخلفية بانتظام لفحص أحدث الإعلانات مع مراعاة سياسات السيرفر لتفادي الحظر.
5. **إشعارات مجانية فورية على الموبايل:**
   - **Telegram Bot (الموصى به):** إشعار أنيق بصوت وتنسيق جذاب مع زر مباشر لفتح الإعلان.
   - **ntfy.sh (بديل فوري بدون حسابات):** تطبيق مجاني يرسل تنبيهات Push للموبايل بضغطة زر.
6. **ذاكرة ذكية لمنع تكرار الإشعارات:** يحفظ الإعلانات التي تم فحصها في ملف `seen_ads.json` حتى لا يرسل نفس الإعلان أكثر من مرة.

## 🚀 خطوات التجهيز في دقيقتين

### 1. الحصول على مفتاح Google Gemini API (مجاني 100%)
1. ادخل على رابط [Google AI Studio](https://aistudio.google.com/app/apikey).
2. سجل دخول بحساب Google الخاص بك واضغط على **Create API key**.
3. انسخ المفتاح وضعْه في ملف `.env` أمام:
   ```env
   GEMINI_API_KEY=AIzaSy...
   ```

---

### 2. إعداد إشعارات الموبايل المجانية (اختر تليجرام أو ntfy)

#### الطريقة الأولى: تليجرام (Telegram Bot - الأفضل والأكثر ثباتاً)
1. افتح تطبيق تليجرام وابحث عن المستخدم الرسمي: **`@BotFather`**.
2. أرسل له الأمر: `/newbot` ثم اختر اسماً للبوت واسم مستخدم ينتهي بـ `bot`.
3. سيعطيك الـ **Token** (مثال: `123456789:ABCdefGhIJK...`)، ضعه في ملف `.env` أمام `TELEGRAM_BOT_TOKEN`.
4. للحصول على الـ **Chat ID** الخاص بك: ابحث في تليجرام عن بوت اسمه **`@userinfobot`** واضغط Start، سيعطيك رقم المعرف الخاص بك (Id)، ضعه في `.env` أمام `TELEGRAM_CHAT_ID`.
5. افتح البوت الجديد الذي أنشأته واضغط **Start** لتفعيل المحادثة معه.

#### الطريقة الثانية (بديل سريع جداً): تطبيق ntfy.sh
1. حمّل تطبيق **ntfy** مجاناً من Google Play أو Apple App Store.
2. افتح التطبيق واضغط على زر `+` واكتب اسم موضوع فريد خاص بك (مثلاً: `ps5_radar_shady_2026`).
3. ضع نفس الاسم في ملف `.env` أمام:
   ```env
   NTFY_TOPIC=ps5_radar_shady_2026
   ```

## 🧪 اختبار الإعدادات قبل التشغيل

يمكنك التأكد من عمل كل جزء بمفرده بسهولة:

### اختبار الذكاء الاصطناعي (Gemini AI):
```powershell
node test-gemini.js
```
*سيقوم باختبار 4 حالات مختلفة (جهاز حقيقي، أسطوانة، دراع فقط، جهاز ps4) لترى كيف يفرق الذكاء الاصطناعي بينهم بدقة.*

### اختبار إشعار الموبايل:
```powershell
node test-notify.js
```
*سيرسل إشعاراً تجريبياً فورياً إلى هاتفك للتأكد من وصول التنبيهات واهتزاز الموبايل.*

## ▶️ تشغيل الاسكربت

لبدء المراقبة المستمرة كل 5 دقائق:

```powershell
node index.js
```
أو:
```powershell
npm start
```

### ماذا يفعل الاسكربت عند أول تشغيل؟
- يقوم بفهرسة الإعلانات الحالية حتى لا يزعجك بإشعارات لأجهزة قديمة منشورة منذ أيام.
- بمجرد نزول **أي إعلان جديد** بعد بدء التشغيل، سيقوم بفلترته بـ Gemini AI ثم إرسال إشعار فوري لهاتفك مع السعر والمكان ورابط الإعلان المباشر.

## ⚙️ تخصيص الإعدادات (`.env`)

| الإعداد | الوصف | القيمة الافتراضية |
| :--- | :--- | :--- |
| `CHECK_INTERVAL_MINUTES` | الفاصل الزمني للبحث بالدقائق | `5` |
| `GEMINI_MODEL` | إصدار موديل الذكاء الاصطناعي | `gemini-2.5-flash` |
| `ALERT_ON_INITIAL_RUN` | إرسال إشعارات للإعلانات القديمة عند أول تشغيل | `false` |
